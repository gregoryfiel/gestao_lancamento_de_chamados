## Contract (minimal) — aligned with handoff Phase B

Draft only (paths/names can change when OpenAPI is published):

| Method | Path | Purpose |
|--------|------|---------|
| `GET` | `/tickets` | List all tickets (pagination TBD) |
| `POST` | `/tickets` | Create ticket (server may assign `id` or accept client `id` — **TBD**) |
| `PATCH` | `/tickets/:id` | Partial update single ticket |
| `DELETE` | `/tickets/:id` | Optional if product needs row delete (SPA has delete today) |
| `POST` | `/tickets/bulk` or `PATCH /tickets` | Optional batch status / bulk ops (sheet today) |
| `GET` | `/export` / `POST` | Optional CSV bridge per handoff |

**Auth:** not in SPA long-term storage — Bearer/session from your IdP or delegated token **via server only** (see `SheetDatabase.tsx` simulated `sp_*` keys — **dev-only, must retire**).
